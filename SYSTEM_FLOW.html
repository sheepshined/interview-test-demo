▍面试启动
START
WebSocket 收到 config 消息
① configure 初始化
岗位 / 难度 / 题量校验；随机分配面试官人设（严谨CTO/温和HR/深挖型）；初始化 streak=0、记录文件
② opening 开场白
LLM 生成开场白（注入人设）→ 流式推送 + TTS 朗读 → 写入对话记忆
①.5 人设分配
random.choice(3种人设) 注入出题/追问/开场/收尾 prompt
NEW
▍出题循环
③ prepare_question 选题
简历技能筛选 + 分类偏好 + 排除已问；按当前自适应难度检索 (BM25+向量+RRF)
⑬ 自适应难度
连续2题≥7分 → 难度+1；<4分 → 立即-1；4-6分重置连击；记录到 difficulty_changes
④ emit_question 出题
上一题回顾 + 对话记忆 + 人设 → LLM 流式生成 → 打字机 + TTS 朗读
⑤ wait_answer 等回答
interrupt() 暂停；期间可收到 answer / hint / end 命令
▍评分与追问
⑥ score_initial 初步评分
四维评分(准确/完整/深度/清晰) + 均值校准；按 hint 次数封顶(1次→8分, 2次→6分)
⑦ 追问分档路由
3 ≤ 分 < 7 → 追问
< 3 或 ≥ 7 → 直接下一题
⑧ prepare+emit_followup 追问
读评分产出定追问方向（禁当候选人说过）→ 流式追问 + TTS
⑨ wait_followup 等补充
interrupt() 暂停；期间可收到 answer / hint / end
⑩ score_combined 合并评分
只拼候选人两段回答重评（防提示词加分幻觉）+ hint 封顶
▍收尾与报告
⑪ finalize_question 归档
写入记录文件 + 触发记忆压缩 + 更新 streak/难度 + 判断是否结束
⑫ closing 收尾
LLM 收尾语（人设+反幻觉约束）→ 推送 interview_ended 事件
⑭ wait_report 等指令
interrupt() 暂停；收到 report 命令才继续
⑮ summary 生成报告
强模型总结（降级链：strong→fast→模板）+ 雷达JSON + 学习建议生成
END
report_ready 推送 → 前端跳转报告页
🧭 条件边汇总
③→④：有题则出题，题库耗尽→收尾
⑤→⑥：收到回答→评分；收到 end→收尾
⑦：3≤分<7→追问；否则→归档
⑨：收到补充→合并评分；end→归档
⑪：已答满/提前结束→收尾；否则→下一题

🔌 WebSocket 消息协议（前端 ↔ 后端）

客户端 → config→ answer→ hint→ end→ report ← 服务端 config_ok← stream_start/chunk/end← decision← hint← interview_ended← report_ready
stream_type: opening / question / followup / closing / report  ·  阶段校验: answer/hint/end 仅限 await_answer/await_followup，report 仅限 await_report
端到端流程：登录 → 选岗/传简历 → InterviewView 连接 WS → sendConfig → 开场(TTS) → 第1题(TTS) → 回答 → 评分 → (低分?) → 追问(TTS) → 补充回答 → 合并评分 → 自适应难度调整 → 循环至答满或提前结束 → 收尾(TTS) → 生成报告 → 跳转 /summary/:reportId → 雷达图 + 强弱项 + 学习建议。

全程串联的记忆：InterviewMemory 按 thread_id 存对话 → 每轮结束超阈值自动压缩为话题级摘要 → 出题/追问只做话题级引用（反幻觉护栏）。
