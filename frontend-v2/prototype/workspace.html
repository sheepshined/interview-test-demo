RAG 评估指标与评测集

Faithfulness 衡量回答是否有上下文支撑；Answer Relevancy 衡量是否切题；Context Recall 衡量检索是否召回必要信息。评测集建议由真实 query + 人工标注的标准答案 + 支撑段落构成，规模 50 条起，用 LLM-as-Judge 时需要抽样人工校准。相关：[[向量检索]]、[[BM25 + 向量混合检索]]。

大模型 评估 3 10-04
Transformer 架构笔记 面试

Self-Attention 通过 Q/K/V 计算序列内相关性，多头机制在不同子空间并行捕捉模式；位置编码补充顺序信息，残差与 LayerNorm 保证深层可训练。

大模型 4 10-03
BGE 模型卡（FlagEmbedding）

BGE 系列中文检索表现稳定，bge-large-zh 适合离线索引，bge-small 适合低延迟场景；reranker 与 embedding 建议配套使用。

大模型 向量检索 2 10-02
BM25 + 向量混合检索

BM25 负责关键词精确命中，向量负责语义相近；RRF 用排名而非分数融合，避免两路分数量纲不一致。权重可调，实践中向量略高、BM25 兜底专有名词。

大模型 RAG 5 09-29
LangGraph 人在回路设计

用 interrupt() 在答题节点挂起，恢复时从 checkpoint 继续，避免重复选同一道题；把「选题 / 流式输出 / 等待作答」拆成独立节点后，恢复语义更清晰。

工程实践 2 09-27
部署清单：并发、缓存与成本

模型服务要做并发限制与排队；检索结果按 query 归一化后缓存；embedding 走批处理降低调用次数；成本估算要按 token 分别统计输入输出。
