03 / LangGraph Engine

面试引擎流程

04 / Retrieval & Scoring

检索与评分

混合检索保证出题精准度，四维评分模型从多维度量化候选人表现，追问机制与提示系统形成完整的自适应面试闭环。

— 01
混合检索出题
BM25 + Vector + RRF
BM25 关键词检索与 BGE 向量相似度通过 RRF 公式融合排序，按岗位/难度/分类多维过滤，排除已出题目避免重复
— 02
四维评分模型
Accuracy · Completeness · Depth · Clarity
LLM 按标准答案 + 得分点评分，输出准确性/完整性/深度/清晰度四维分数；总分与四维均值校准防自相矛盾
— 03
追问与合并重评
Followup · Combined Scoring
初始得分 3-6 分触发针对性追问，追问后拼接两段回答合并重评；低于 3 分或高于 7 分直接进入下一题
— 04
反幻觉与对话记忆
Anti-Hallucination · Memory
出题衔接只读候选人原文，切断评分产出回流；话题级摘要护栏禁止逐字引用，窗口内精准回指具体内容
05 / Auth & Isolation

鉴权与隔离

生产级 JWT 用户体系，全接口与 WebSocket 握手鉴权，报告/会话/知识库均按用户隔离，杜绝跨用户数据泄露。

01 · AUTH
JWT 签发与校验
HS256 签名，默认 24h 过期；除 login/register 外所有 REST 接口经 Depends(get_current_user) 校验 Bearer Token
02 · USER
用户注册与密码安全
SQLite users.db 存储用户表，bcrypt 密码哈希加盐；用户名 3-20 位规则校验，预置演示账号 admin/123123
03 · REPORT
报告按用户隔离
报告 JSON 写入 username 字段；/api/reports 列表与详情/雷达仅返回归属用户的报告；旧报告无 username 字段归 admin
04 · SESSION
WebSocket 会话隔离
WS 握手需 ?token=jwt，无效拒绝握手 (HTTP 403)；恢复他人 thread_id 被拒绝；会话列表按 username 过滤
05 · KB
知识库按用户隔离
knowledge.db 按 username 分区；向量库 kb_chroma 独立于题库 chroma_db；笔记/图谱/RAG 问答全链路用户隔离
06 · RECORD
面试记录管理
DELETE 接口支持记录删除，文件名正则校验防路径穿越；记录头标注用户归属，非本人返回 404；前端悬停删除+确认
06 / Knowledge Base

个人知识库

面试报告薄弱点一键沉淀进知识库，形成「面试 → 复盘 → 学习 → 再面试」的成长闭环。支持双链笔记、知识图谱、RAG 问答与文件批量入库。

01
双链笔记
Bi-linked Notes
[[wiki]] 语法双向链接；笔记表不存边，链接为解析衍生视图；编辑器侧栏实时显示反向链接
CRUD · Wiki · Backlinks
02
知识图谱
Knowledge Graph
Cytoscape.js 力导向布局；节点大小=连接数；hover 高亮邻居；虚节点=链接到不存在的标题，点击即创建
Force · Semantic · Virtual
03
RAG 问答
Retrieval Augmented QA
RAG 对话 双栏布局，SQLite 持久化会话与消息；检索回查笔记全文（4000字/条）；参考来源卡片可跳转；sparse 提示导入
Search · LLM · Persist
04
文件入库
File Upload & Structure
多文件批量上传 → 模型提取原文 → LLM 结构化 建笔记 → 向量同步；AI 自动分类与内容整理
Extract · Structure · Sync
